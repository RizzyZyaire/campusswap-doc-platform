# 前端源码说明（CampusSwap 校内文档平台）

> 本文件是**前端源码包**的根目录说明：源码在 `frontend/`，离线页面画廊在 `页面展示（离线可点）/`。
> 先看哪个：只想看界面 → 双击 `页面展示（离线可点）\index.html`；想看代码 → 进 `frontend/`。

## 1. 技术栈

| 层 | 选型 |
|---|---|
| 框架 | Vue 3.5（`<script setup lang="ts">`）+ TypeScript（strict）+ Vite 6 |
| 状态/路由 | Pinia 2 + Vue Router 4 |
| 样式 | Tailwind CSS 3 + 少量全局 CSS 变量（6 套主题） |
| 请求 | Axios（统一拦截器：拆 `ResponseResult` 信封、401 广播登出） |
| 内容渲染 | markdown-it + DOMPurify（先转义再插高亮标记，防 XSS） |
| 包管理 | **pnpm**（`pnpm-lock.yaml` / `pnpm-workspace.yaml` / `.npmrc`），Node ≥ 20 |

## 2. 目录结构

```text
frontend/
├── package.json / pnpm-lock.yaml / pnpm-workspace.yaml / .npmrc
├── vite.config.ts              # dev 端口 5173，/api 与 /uploads 代理到后端 10087
├── index.html / tsconfig.json / tailwind.config.js / postcss.config.js / eslint.config.js
├── public/                     # 静态图标等
├── scripts/                    # 可选自检脚本（预览稿生成、截图、类名体检、409 复现）
└── src/
    ├── api/                    # Axios 封装 + 各业务域接口
    ├── types/                  # 与后端契约一一对应的 TS 类型
    ├── stores/                 # Pinia（登录态、主题等）
    ├── router/                 # 路由表 + 登录/权限守卫
    ├── views/                  # 页面：登录、工作台、检索、详情、编辑、审核、治理、系统管理
    ├── components/             # 通用组件（Markdown 预览、批量导入、分页、四态等）
    ├── layouts/                # 顶栏 / 侧栏 / 主布局
    ├── styles/                 # 主题变量与全局样式
    └── utils/                  # 权限、格式化、校验等
```

## 3. 启动（需要后端已跑在 10087）

```bash
cd frontend
pnpm i          # 安装依赖（等价 pnpm install）
pnpm dev        # 开发服务器 http://localhost:5173
```

演示账号：`admin / Admin@123`（SYS_ADMIN）、`docadmin / Doc@123456`（DOC_ADMIN）、`staff / Staff@123`（STAFF）。
后端启动方式见同目录的 `源码阅读说明.md`（在后端包根目录）或本包 `页面展示（离线可点）/说明.md`。

## 4. 构建与四条门禁

```bash
cd frontend
pnpm run typecheck      # vue-tsc --noEmit：类型检查
pnpm run lint           # eslint . --max-warnings 0
pnpm run build          # 先 typecheck 再 vite build，产物在 dist/
pnpm run check-classes  # Tailwind 类名体检（动态拼接的类必须在白名单里）
```

四条全绿才视为本前端可交付（本次交付前四条均通过）。

## 5. 离线快照与画廊（不用启动任何服务）

- **入口**：`页面展示（离线可点）\index.html`（双击打开）。
- 画廊里每张缩略图点开，是对应页面的**离线快照**（`页面展示（离线可点）\快照\*.html`，共 13 页）：渲染后的真实 DOM + 内联 CSS，图片在 `快照\assets\` 下，全部相对路径，**断网/换机器也能看**。
- `截图\` 13 张 2K 截图；`截图-补充\` 23 张开发过程截图；`说明.md` 是画廊自身的说明。
- 快照是静态副本：按钮点击、翻页、搜索等交互不会响应；要看可交互效果请按第 3 节把前后端跑起来。

## 6. 与后端 jar 的关系（构建产物由谁托管）

`pnpm run build` 生成 `frontend/dist/`（`index.html` + `assets/` 下的 js/css/图片）。
后端 `backend/pom.xml` 的 `bundle-frontend-dist` 步骤会在执行 `mvnw package` 时把 `../frontend/dist` 复制进 jar 的 `BOOT-INF/classes/static/`，由 Spring Boot 一并托管：

- 开发期：前端 5173（Vite）→ `/api`、`/uploads` 代理到后端 10087；
- 交付运行版：`campusswap-backend-1.0.0.jar` 一个 jar 同时提供页面与接口（prod 端口 10180，`static/index.html` 存在时注册前端路由回落）。

因此**本源码包不含 `dist/`**（`node_modules/`、`dist/`、`.git/` 均已排除），需要时按第 4 节重新构建即可；运行版 jar 里才是构建产物。
