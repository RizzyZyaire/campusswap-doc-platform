## 二、分镜时间轴（总 3:00）

> 每一段都写清"镜头给谁 / 做什么 / 说什么"。解说不用逐字念，抓住关键词即可。

| 时间 | 镜头 | 操作 | 解说要点 |
|---|---|---|---|
| **0:00–0:30** | 终端 | `redis-cli ping` → 看到 **PONG**；再敲 `redis-cli keys "login:token:*"` | "这是 Redis，登录状态真实存在 Redis 里 —— 现在有 N 个在线会话键；`ping` 返回 PONG 说明中间件正常" |
| **0:30–0:55** | 浏览器标签① | 打开 `http://localhost:9200`，展示 JSON | "Elasticsearch 9.4.5，装了 analysis-ik 中文分词器（`_cat/plugins` 可看到）" |
| **0:55–1:15** | 浏览器标签② | 登录 `localhost:15672` → 点 **Queues** → 展示 `campusswap.search.rebuild` 与 `campusswap.search.rebuild.dlq` | "RabbitMQ 控制台，左边这两个队列就是索引重建的主队列和死信队列，拓扑真实存在" |
| **1:15–1:35** | DBeaver | 展开 `campusswap_db` 的 15 张表 → `select * from sys_operation_log order by id desc limit 5;` | "数据库 15 张表，这是操作日志表，已经记下了刚才那些写操作" |
| **1:35–1:55** | 终端 / IDEA | 启动后端，日志无报错，滚到 `Started CampusSwapApplication in x seconds` 与 `Tomcat started on port 10087` | "后端启动，日志没有报错，端口 10087" |
| **1:55–2:30** | 浏览器标签③ | 登录 admin → 工作台 → **文档模块**：新建一篇 → 编辑 → 发布；切到 **分类模块**：新增一个分类 → 改名 → 删除；**切回 DBeaver 刷新，展示数据变化** | "任选两个业务模块做增删改查，这是文档、这是分类；数据库里能看到刚写的记录"（这段可后期 1.25× 变速） |
| **2:30–2:50** | 浏览器标签③ | 检索页：点**「重建检索索引」** → 界面显示 `重建任务：已提交 → 执行中 → 已完成`（**异步证据**）→ 输入关键词（如"支教"）→ 展示结果与 **黄色高亮**；可选：填时间范围/标签做组合筛选 | "重建任务提交给 RabbitMQ，后台消费者执行 —— 接口 3 毫秒就返回了；检索结果带高亮，还能按时间范围、标签组合筛选" |
| **2:50–3:00** | 浏览器标签③ | 点右上角**退出登录** → 回到登录页 | "退出登录，token 立即失效" |
| 彩蛋（可选，放片尾 5–10 秒） | 浏览器标签③ | 明暗主题切换 / 工作台统计 / Markdown 导入 | "另外还做了明暗主题、Markdown 导入这些" |

**关键**：第 4 步的"待办 → 执行中 → 已完成"画面是**异步索引重建的唯一可视化证据**，一定要拍到；高亮效果要放大或后期加箭头。

## 三、怎么录

| 方案 | 操作 | 适用 |
|---|---|---|
| **Xbox Game Bar（最快）** | `Win + Alt + R` 开始 / 停止；录制文件在 `此电脑 → 视频 → 捕获` | 只要一段整镜、不做画面分区 |
| **OBS Studio（推荐）** | 添加"显示器采集"→ 输出 1920×1080 / 30fps / 码率 8000kbps → 开始录制 | 想同时录**麦克风解说**或做画中画 |
| **剪映自带录屏** | 剪映 → 录屏 → 选区域 | 想少一个软件 |

录音建议：如果不用 OBS 录麦，就用手机录音或剪映的"文本朗读"配音，后期对轨。

## 四、剪映后期逐步流程

1. **新建工程**：剪映 → 开始创作 → 导入录屏 mp4（拖到时间线）。
2. **粗剪**：播放一遍，遇到等待/输错/卡顿就 `Ctrl+B` 分割后删除，只留"顺"的那一遍。
3. **变速**：把"输账号密码""数据库刷新"这类重复镜头右键 → 变速 → 常规变速 **1.25×~2×**，把总时长压到 **3:00 以内**。
4. **章节标题**（关键，老师在按步骤对分）：在每段开头加文本条，写清步骤名 —— `① 中间件检查` `② 启动后端` `③ 启动前端 · 增删改查` `④ 索引重建 + 全文检索` `⑤ 退出登录`。放在左上角，停留 2 秒。
5. **字幕**：文本 → 智能字幕 → 识别字幕（或用"文本朗读"生成配音后自动对轴）。错别字手动改（"Elasticsearch""RabbitMQ""Redis"这类专有名词必查）。
6. **重点标注**：用贴纸/形状里的箭头或方框，指向这几处 —— 终端里的 `PONG`、ES 的版本号 JSON、RabbitMQ 的**两个队列名**、DBeaver 里新增的那行数据、检索结果的**高亮**、重建任务的**状态字样**。每处停留 1.5~2 秒。
7. **放大局部**：对终端/控制台里的小字，用"画面 → 裁剪/缩放"或关键帧放大到 130%~150%。
8. **转场**：章节之间加"叠化"0.3 秒即可，别用花哨的；同章节内不要加转场。
9. **音频**：原声（解说/键盘音）保留；BGM 从剪映音乐库选"轻电子/科技感"，音量拉到 **-20dB** 左右，**别盖过人声**。
10. **封面**：用工作台截图 + 标题文字「CampusSwap 师大文档管理平台 · 功能演示」。
11. **导出**：右上角导出 → 分辨率 **1080P**、帧率 **30fps**、码率"推荐"（约 8~12 Mbps）→ 得到 mp4。
12. **自查**：导出后完整看一遍，确认 ① 五个步骤画面齐全 ② 没有卡顿/黑屏 ③ **没有泄露密码等敏感信息**（DBeaver 连接串、终端里如果出现密码，用马赛克/贴纸遮掉）④ 时长 ≤ 3:30。

## 七、常见坑

1. **录屏时 ES 索引是空的** → 检索那一步出不来结果。**录制前先点一次「重建检索索引」**。
2. **RabbitMQ 没启** → 重建任务会显示"消息队列不可用（5672 连接被拒）"。先启动再录。
3. **浏览器缩放不是 100%** → 页面元素错位、字看不清。`Ctrl+0` 复位。
4. **DBeaver 用 caching_sha2 报 Public Key Retrieval** → 用"Driver properties"勾 `allowPublicKeyRetrieval=true`（本项目 MySQL 账号已改成 `mysql_native_password`，一般不会遇到）。
5. **录屏文件太大** → 用 OBS 时把码率降到 6000~8000 kbps；Xbox Game Bar 默认码率偏高，可在"设置 → 捕获"里调。
6. **解说与画面对不上** → 先把画面剪好，再加"文本朗读"生成配音，最后微调字幕时间轴。
