## 一、录制前准备（照单打勾，约 15 分钟）

### 1.0 一句话版本

> **双击一个 `campusswap-start.cmd`，它会把 Elasticsearch / RabbitMQ / MySQL / Redis / 后端 / 前端按顺序全拉起来 → 等它打印 `[7/7] done` → 浏览器备好 3 个标签页 → 试录 10 秒确认画面干净。**

### 1.1 ✅ 启动顺序：一键脚本已经全包了（含 RabbitMQ）

**结论先说**：现在只要**双击一次** `D:\DevEnv\scripts\campusswap-start.cmd`，它就会按 **中间件在前、后端在后** 的顺序把 7 步全部走完：

```
[1/7] Elasticsearch 9200
[2/7] RabbitMQ 5672 / 15672        ← 2026-10-14 新增（原来漏了这一步）
[3/7] MySQL80 和 Redis 服务
[4/7] 演示库是否重新灌种子数据
[5/7] 后端 10087
[6/7] 前端 5173
[7/7] 完成，打开网站
```

**为什么这一步很重要（原来漏掉时的后果）**：后端一启动就会去连 RabbitMQ，如果 broker 没起来，启动日志会被这样的 ERROR 刷屏 —— 直接违反老师「启动日志无报错」的要求：

```
ERROR ... SimpleMessageListenerContainer : Failed to check/redeclare auto-delete queue(s).
WARN  ... Consumer raised exception ... AmqpConnectException: Connection refused
```

现在脚本会**先把 RabbitMQ 拉起来并等它就绪**（约 10~20 秒，实测从点下去到 5672 可连约 **4.6 秒**），再去启动后端，所以启动日志是干净的。

> **脚本对 RabbitMQ 的行为**
> - 已经在跑 → 打印 `already running - skipped`，**不会**起第二个实例；
> - 没在跑 → 从 `D:\DevEnv\13_RabbitMQ\rabbitmq_server-*`（通配，不钉版本号）找到安装目录拉起，等到 5672 可连才继续；
> - 本机没装 → 打印 `no local RabbitMQ found`，其余步骤照常（索引重建会报 FAILED，其余功能不受影响）。

> **万一你只想单独启动 RabbitMQ**（比如脚本跑到一半你把 broker 关了）：用 `D:\dsh-workspace\scripts\rabbitmq-start.cmd`，或按 「1.3 手动启动 RabbitMQ 的完整命令」 手敲。

**停止**：双击 `D:\DevEnv\scripts\campusswap-stop.cmd`。它会**优雅停** RabbitMQ（走 `rabbitmqctl stop`，日志里能看到 `Stopping and halting node ...`，队列和定义都会先落盘），而不是强杀进程。

### 1.3 手动启动 RabbitMQ 的完整命令

> 一般用不到（一键脚本 `[2/7]` 已经管了）。只有在你想**单独**把 broker 再拉起来时才需要。

开一个 **命令提示符** 或 **PowerShell**，逐行敲（第 1~3 行是必须的，第 2 行少了会把数据写到 C 盘）：

```cmd
set ERLANG_HOME=D:\DevEnv\12_Erlang
set RABBITMQ_BASE=D:\DevEnv\13_RabbitMQ\data
cd /d D:\DevEnv\13_RabbitMQ\rabbitmq_server-4.0.9
sbin\rabbitmq-server.bat
```

**你应该看到**：最后几行出现类似

```
Starting broker... completed with 6 plugins.
```

并且这个窗口**不要关**（关了 broker 就停了）。大约 10~15 秒后 `5672` 和 `15672` 就通了。

> 冷启动实测：从敲下命令到 5672＋15672 都 LISTENING 约 **10.4 秒**。

### 1.4 四个中间件端口自检

开一个 PowerShell，整段复制粘贴：

```powershell
foreach($p in 3306,6379,9200,5672,15672,10087,5173){
  $c = Test-NetConnection -ComputerName 127.0.0.1 -Port $p -InformationLevel Quiet -WarningAction SilentlyContinue
  "{0,-6} {1}" -f $p, $(if($c){'OPEN'}else{'CLOSED'})
}
```

**你应该看到**（7 行全部 OPEN）：

```
3306   OPEN      # MySQL
6379   OPEN      # Redis
9200   OPEN      # Elasticsearch
5672   OPEN      # RabbitMQ AMQP
15672  OPEN      # RabbitMQ 管理台
10087  OPEN      # 后端
5173   OPEN      # 前端
```

哪一行是 CLOSED，就回去看 「八、常见坑」 对应那一条。

## 三、逐步操作手册

> 下面每一小段都按同一个格式写：**要打开什么 → 照着敲/点 → 你应该看到什么 → 解说稿（照着念）**。

### 第 ① 步：中间件检查（4 小段，约 78 秒）

#### ①-1　Redis 检查（预计 22 秒）

**要打开的窗口**：一个 **Windows PowerShell** 或 **命令提示符** 窗口（按 `Win + R`，输入 `powershell`，回车）。

**照着敲**（一行一行敲，每行敲完回车）：

```cmd
cd /d D:\DevEnv\04_Redis
redis-cli.exe ping
```

**你应该看到**：

```
PONG
```

> 如果看到 `'redis-cli.exe' 不是内部或外部命令`，说明第一行的 `cd` 没生效——回到第一行重敲一次。

**接着敲这一行**（这是老师扣分表里"登录状态是否真实接入 Redis"的直接证据）：

```cmd
redis-cli.exe keys "login:token:*"
```

**你应该看到**：若干行以 `login:token:eyJhbGciOi...` 开头的长字符串（**本次实测 7 个**）。

> 如果一行都没有：先在浏览器里登录一次前端（见 ③-1），再回来敲这条命令。

**再敲这一行**（权限缓存，可选）：

```cmd
redis-cli.exe keys "perm:*"
```

**你应该看到**：至少一行 `perm:user:1`（权限合并结果的 30 分钟缓存）。

**解说稿（照着念）**：

> 「这是 Redis。`ping` 返回 PONG，说明 Redis 正常运行。下面这些 `login:token` 开头的键，就是每个登录用户真实存在 Redis 里的会话——不是写死的假登录。」

#### ①-4　数据库检查（预计 16 秒）

**要打开的窗口**：DBeaver。

> **本教程无法替你验证 DBeaver 的图形界面操作**（我没有 GUI 操作能力），下面按 DBeaver 的实际界面结构写，并同时给出**已实测的等价命令行**。两条路任选一条录都行——老师的要求是"使用任意一个数据库客户端操作，能够看到创建的表以及表中的数据"。

**DBeaver 路径（图形操作）**：

1. 打开 DBeaver（开始菜单或桌面 `DevEnv 工具` 文件夹里的 DBeaver 快捷方式）。
2. 左侧「数据库导航」面板里找到连接 **`campusswap_db`**，双击展开。
   > ⚠️ 结构是：连接（书签）→ **`数据库`** 文件夹 → **`campusswap_db`** 节点。**14 张业务表 ＋ 1 张日志表都挂在 `campusswap_db` 这个节点下面**，连接节点本身没有"表/视图"文件夹。
3. 展开 `campusswap_db` → 展开 **`表`** → 看到 **15 张表**：
   `doc_category`、`doc_document`、`doc_document_tag_rel`、`doc_favorite`、`doc_tag`、`doc_version`、`sys_dept`、`sys_dept_role`、`sys_operation_log`、`sys_permission`、`sys_role`、`sys_role_permission`、`sys_user`、`sys_user_permission`、`sys_user_role`
4. 双击 `doc_document` → 打开「数据」页签 → 看到 45 行文档数据。
5. 在 SQL 编辑器里跑一句（`Ctrl + ]` 新建 SQL 脚本）：

```sql
select count(*) as 文档总数 from campusswap_db.doc_document;
```

**解说稿（照着念）**：

> 「这一步做 Elasticsearch 索引的全量重建。点下去，接口 19 毫秒就返回了"已提交"，真正的重建任务交给 RabbitMQ 后台消费者去跑。徽标从"已提交"变成"执行中"，最后变成"已完成，28 篇"——前端是在轮询任务状态，这是真实的异步执行。」

> ⚠️ **别被引擎徽标误导**：重建完成后页面会重新查一次「不带关键词的文档列表」，引擎徽标仍然显示 **`检索引擎：MySQL`**。**这是正常的**（无关键词时本来就走 MySQL 列表查询）。判断索引重建成功与否，**看的是绿色的「重建任务：已完成 · 28 篇」徽标**。等你输入关键词搜索，引擎徽标就会变成 `Elasticsearch（IK 分词）`。

## 五、剪映后期逐步流程（照着做）

> 下面用的是 **剪映专业版（Windows 桌面版）** 的界面。**我无法运行剪映替你验证菜单层级**，所以每个功能我都写了「菜单在哪儿 + 点什么」，如果你的版本菜单文字略有不同，按同样的关键词找即可。

### 5.0 先规划好再动手

时间线目标：**总时长 ≤ 3:00**。先按 「二、分镜时间轴」 在心里过一遍，知道哪几段要砍、哪几段必须留。

### 5.1 新建工程 + 导入

1. 双击桌面 **`剪映专业版`** 快捷方式。
2. 首页点 **`开始创作`** → 进入编辑界面。
3. 点左上角 **`媒体`** 面板里的 **`导入`** 按钮（或直接把 mp4 **拖进** 媒体面板）。
4. 把导入进来的视频**从媒体面板拖到下方时间线**的轨道上。

### 5.2 粗剪（删掉等待和失误）

1. 把时间指针拖到要砍掉的**起点**，按 **`Ctrl + B`**（= 分割），再拖到**终点**，再按 **`Ctrl + B`**。
2. 中间那段变成独立片段，**点中它** → 按 **`Delete`** 删掉。
3. 同理删掉：输错密码重来的镜头、等索引重建的空白镜头、鼠标乱找按钮的镜头。

> **也可以用「右键」**：在时间线片段上 **右键 → `分割`**。
> **删完会出现空隙**：把后面的片段**按住往左拖**贴上来（自动吸附）。

### 5.3 变速（压时长到 3 分钟以内）

**菜单层级**（右键路线）：

1. 在时间线上 **点中**要变速的片段（选中后片段四周有白框）。
2. **右键** → 弹出菜单 → 选 **`变速`** → 子菜单里选 **`常规变速`**。
3. 弹出的面板里有一个「倍速」区，拖动滑块或直接在数值框里输入，例如 **`1.5x`** 或 **`2x`**。
   > 面板里还有「声音变调」开关，**保持关闭**；如果这段没有解说只有环境音，也可以关掉「保留音频」。
4. 点 **`确定`**。

**建议变速的段落**：输账号密码、数据库刷新、等待索引重建、页面加载。**倍速 1.5×~2×**。

**不要变速的段落**：`PONG`、ES 版本号 JSON、RabbitMQ 队列名、数据库行数、检索高亮、`重建任务：已完成`。这些是老师要对分的地方，**保持原速**。

### 5.4 章节标题条（关键，老师在按步骤对分）

**目的**：让老师一眼看出"这 5 步我都拍了"。

**菜单层级**：

1. 左上角切到 **`文本`** 面板 → 点 **`默认文本`** 右下角的 **`+`**（或直接把「默认文本」拖到时间线**上层轨道**）。
2. 时间线上多出一条文本片段，**拖它的两端**调整长度，让它盖住对应章节的开头。
3. 右侧出现 **`文本`** 属性面板 → 在 **`内容`** 输入框里填标题文字。
4. 切到 **`布局`** 页签 → 调 **`位置`**：把 X/Y 调成**左上角**（大致 `X = -600, Y = 300`，具体看你画布大小，拖到画面左上角留出边距即可）。
5. 切到 **`字体`** 页签 → 字号调到 **`8`~`10`**（约合画面高度的 4%），字体选**黑体 / 微软雅黑**，颜色**白色**，勾上 **`描边`**（黑色，宽度 2~3），保证任何背景上都看得清。

**做 5 条，文字分别是**：

| 章节 | 标题文字 | 出现时间 | 停留 |
|---|---|---|---|
| ① | `① 中间件检查 · Redis / ES / RabbitMQ / 数据库` | 0:00 | 2 秒 |
| ② | `② 启动后端 · 日志无报错` | 1:18 | 2 秒 |
| ③ | `③ 启动前端 · 登录 · 两个模块增删改查` | 1:36 | 2 秒 |
| ④ | `④ 索引全量重建 · 全文检索与高亮` | 2:32 | 2 秒 |
| ⑤ | `⑤ 退出登录` | 2:56 | 2 秒 |

> 时间点按你实际剪辑后的位置微调，不用卡得一模一样。

### 5.5 字幕与配音（照着做）

**路线 A：智能字幕（先有声音再识别）**

1. 左上角切到 **`文本`** 面板 → 点 **`智能字幕`** → 点 **`开始识别`**。
2. 等进度条走完，时间线上会出现一条条字幕片段，右侧可逐条改文字。

**路线 B：文本朗读（没有麦克风时用这个）**

1. 左上角 **`文本`** → **`默认文本`** 拖到时间线 → 在右侧 **`文本`** 面板填解说词。
2. 右侧切到 **`朗读`** 页签 → 挑一个音色（推荐「**男声 · 解说小帅**」或「**女声 · 译制腔**」这类播报音色）→ 点 **`开始朗读`**。
3. 生成后把这条音频**拖到音频轨**，再把文本框删除（或保留当字幕）。
4. 逐条对齐：把音频片段拖到和画面对应的位置。

**⚠️ 必查的专有名词**（语音识别和朗读都可能弄错，逐条核对）：

| 正确写法 | 常见错误 |

| `RabbitMQ` | 兔子MQ / 拉比特MQ / Rabbit MQ |
| `MySQL` | 买SQL / My Sequel |
| `IK 分词器` | ik / 一K |
| `campusswap.search.rebuild` | campus swap / search rebuild（点号别丢） |
| `JWT` | jwt / J.W.T |
| `Markdown` | mark down / 马克当 |
| `增删改查` | 增删改差 |
| `PONG` | pong / 胖 |

### 5.6 重点标注（红框 / 箭头 / 放大）

| 现象 | 原因 | 怎么办 |
|---|---|---|
| **后端启动日志刷满 `AmqpConnectException: Connection refused`** | **RabbitMQ 没启动** | 重新跑一次 `campusswap-start.cmd`（`[2/7]` 会把 RabbitMQ 补起来），**再重启后端**；或按 「1.3 手动启动 RabbitMQ 的完整命令」 单独起 |

| 重建任务徽标显示 **`重建任务：失败`** | RabbitMQ 或 ES 掉了 | 检查 5672 / 9200 端口；失败消息会进死信队列 `campusswap.search.rebuild.dlq` |

| 页面样式错乱、元素错位 | 浏览器缩放不是 100% | 在浏览器里按 **`Ctrl + 0`** |
| 检索不出结果 | ES 索引是空的 | 录屏前先在检索页点一次「重建检索索引」，等徽标变 **已完成** |
