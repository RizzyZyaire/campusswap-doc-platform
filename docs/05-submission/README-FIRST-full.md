## 全文检索（Elasticsearch，可选）

检索页支持 **Elasticsearch + IK 中文分词** 的全文检索：搜索前可以选 **检索范围**（标题 / 正文 / 标题+摘要+正文），
结果按相关度排序并把**关键词高亮**出来（`<mark>`），还能看到"命中位置"与相关度分数。

- **本包不带 Elasticsearch**（解压后约 950 MB），所以默认走 MySQL 引擎，功能照常可用；
- 页面上会如实显示当前引擎（`Elasticsearch（IK 分词）` 或 `MySQL`）；
- 想启用 ES：按老师《10.1-安装手册》装好 Elasticsearch + analysis-ik 后重新运行本包即可 —— 启动脚本会自动识别并连上它
  （认 `ES_HOME` 环境变量，或 `D:\Environment\elasticsearch-*` / 本机同盘安装目录），READY 摘要里会写明当前检索引擎；
- 首次启用后请在检索页点一次 **「重建检索索引」**（管理员可见），把已发布文档同步进 ES。

> 检索密钥/账号与其它功能无关；ES 没装或没启动都不会报错，只会自动降级。

## 本次更新了什么（M13~M16）

> 本包里的 `app\campusswap-backend-1.0.0.jar` 已于 **2026-10-14** 重新打包（旧 jar 停在 10-11 的 M8 版本，
> 不含下面这四个里程碑）。**下面这些新功能都要用管理员账号 `admin / Admin@123` 登录才看得到**，
> 普通账号（docadmin / staff）看不到入口。

- **登录改用 JWT（HS256）**：登录成功后返回的是 JWT 令牌（算法 `HS256`，默认 2 小时有效），
  登录状态**仍然存在 Redis 里**，所以「退出登录后令牌立即失效」「管理员改权限即时生效」这些能力都保持不变。
- **新增「操作日志」页**：登录后左侧菜单 **系统运维 → 操作日志**（**仅管理员可见**，入口 `/admin/logs`），
  可按 账号 / 模块 / 动作 / 成功与否 / 时间范围 组合查询历史操作记录（密码等敏感入参已脱敏成 `***`）。
  > ✅ **已修复（2026-10-14，本包自带数据库）**：包内的便携 MySQL 原来只有 **14 张表**，缺 M14 新增的
  > `sys_operation_log`，而 demo 配置是 `ddl-auto: none`（应用从不自己改表）——那时**直接双击启动本包，
  > 「操作日志」页会报「服务器开小差了」（`GET /api/logs` 返回 500）**。
  > 现已用「纯新增」方式在包内库里补建该表（只 1 条 `DROP TABLE IF EXISTS` + 1 条 `CREATE TABLE`，
  > **未改动其它 14 张表的任何数据与结构**）：表数 14 → 15、索引 27 → 30，其它 14 张表行数逐张比对无变化。
  > 实测：双击 `1-启动网站（双击我）.cmd` 冷启动后 admin/Admin@123 登录返回 200、
  > `GET /api/logs?pageSize=1` **返回 200**（修复前是 500），且登录动作本身已被记入日志
  > （`module=认证` / `action=登录` / 密码已脱敏成 `***`）。
- **全文检索支持组合筛选**：检索页多了 **起始日期、结束日期、标签** 三个输入框（时间范围按**发布时间**过滤），
  可以和 关键词、检索范围、分类 **任意叠加**。
- **「重建检索索引」改成异步任务**：点下去不再卡住页面，界面依次显示
  **已提交 → 执行中 → 已完成**（任务走 RabbitMQ 队列，由后台消费者执行）。
  ⚠️ 本机没装 / 没启动 RabbitMQ 时，会提示 **「消息队列不可用（请确认 RabbitMQ 已启动，5672 端口可连）」**
  并以**失败**状态返回，**其它功能完全不受影响**（检索照常可用，实测该接口本身仍返回 200）。
