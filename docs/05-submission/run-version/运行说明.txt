运行说明（免安装运行版）
================================================================
这个文件夹里的东西能让你**不装 JDK、不装数据库、不装 Node** 就把网站跑起来。

一、启动
----------------------------------------------------------------
双击：1-启动网站（双击我）.cmd
窗口会依次显示 5 步：便携 MySQL(3307) → 便携 Redis(6380) → Elasticsearch(9200，本机装了才用) → 网站(10090) → 打开浏览器
看到 READY 就是好了，浏览器会自动打开：
      http://localhost:10090
没自动打开就自己输这个地址（用 Edge / Chrome 都行）。

演示账号：
      admin    / Admin@123      系统管理员（39 个权限点，全部功能）
      docadmin / Doc@123456     文档管理员（审核、治理、分类标签）
      staff    / Staff@123      普通员工（写文档、检索、我的文档、派生、收藏）

⚠️ 第一次启动可能慢（1~2 分钟）：Windows Defender 会扫描刚解压出来的 20 多万个文件。
   窗口里每 15 秒会显示一次"还在等 MySQL"，属于正常，**请等它自己走完**。
   第二次以后通常 15 秒内就绪（实测 12.4~14.2 秒）。

二、停止
----------------------------------------------------------------
双击：2-停止网站（双击我）.cmd
它会干净地关掉 MySQL / Redis / 网站（MySQL 用 mysqladmin shutdown，不会损坏数据）；本机若有 Elasticsearch 也一并停掉

三、这个文件夹里装了什么
----------------------------------------------------------------
   app\      Spring Boot 打包产物（一个 jar 里同时含后端接口和构建好的前端页面）
   runtime\  精简 Java 运行时（jlink 生成，约 44 MB，所以不用装 JDK）
   mysql\    便携 MySQL 8.0.46 + 已初始化的 data 目录
             （14 张表 / 27 个索引 / 45 篇文档 / 3 个账号 / 99 条版本留痕都在里面）
   redis\    便携 Redis（登录令牌与权限缓存用）
   logs\     运行日志（网站日志 demo-app.log；MySQL 的报错在 mysql\launcher.err）

端口是 3307 / 6380 / 10090，故意避开 3306 / 6379 / 10087，
所以**不影响**你电脑上已经装的 MySQL、Redis 或其它服务；也不装服务、不写注册表。

四、出问题先看这里
----------------------------------------------------------------
1) 双击后窗口一闪就没 / 提示缺文件
   → 99% 是没有完整解压（在压缩软件里直接双击只会解出那一个文件）。
     请把整个压缩包解压到硬盘上，再进这个文件夹双击。

2) MySQL 窗口一闪而过，启动器里写着 VCRUNTIME140.dll 之类
   → 缺微软 C++ 运行库：装一次 "Microsoft Visual C++ 2015-2022 Redistributable (x64)"
     （微软官网免费，约 25 MB），装完重新双击 1-启动网站。

3) 等了两三分钟仍是 "MySQL did not come up"
   → 启动器会把 mysql\launcher.err 的最后几行直接打在屏幕上，把那几行发我即可。
     常见原因是杀毒软件拦截了 mysqld.exe：把它所在文件夹加入白名单再试。

4) 提示 10090 已被占用
   → 上次没关干净。先双击 2-停止网站（双击我）.cmd，再重新启动。

5) 页面能开但登录报错
   → 多半是 MySQL 还没完全就绪，等 10 秒刷新一次；仍不行看 logs\demo-app.log 末尾。

6) 想把数据恢复到最初的 45 篇文档
   → 先 2-停止网站，然后把 mysql\data 整个删掉，从压缩包里重新解压一份 mysql\data
     （或者用源码版 backend\sql\{schema.sql,data.sql} 重灌，root 空口令仅限本机演示）。
