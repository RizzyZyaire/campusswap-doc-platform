CampusSwap 文档管理平台 —— 免安装运行说明（双击就能看）
================================================================

一、怎么打开
----------------------------------------------------------------
1. 先把压缩包【完整解压】到任意目录（不要直接在压缩软件里双击运行）；
2. 进入本文件夹，双击：1-start.cmd
3. 等 10~30 秒（第一次启动要解压前端资源），浏览器会自动打开：
       http://localhost:10090
   没自动打开就手动在浏览器里输入这个地址。

演示账号（数据已经随包带好，不用建库、不用导入 SQL）：
   admin    / Admin@123     系统管理员（39 个权限点，全部功能）
   docadmin / Doc@123456    文档管理员（审核、归档、驳回、分类标签）
   staff    / Staff@123     普通员工（建文档、编辑自己的、检索、派生、收藏）

停止：双击 2-stop.cmd（会干净地关掉 MySQL/Redis/网站三个进程）。


二、这个包里装了什么
----------------------------------------------------------------
   app\      Spring Boot 打包产物（一个 jar 里同时含后端接口与构建好的前端页面）
   runtime\  精简 Java 运行时（jlink 生成，约 44 MB，所以【不用装 JDK】）
   mysql\    便携 MySQL 8.0.46（约 215 MB）+ 已初始化并灌好数据的 data 目录
             —— 14 张表 / 27 个索引 / 45 篇文档 / 3 个演示账号都在里面
   redis\    便携 Redis（登录令牌与权限缓存用，约 2 MB）
   logs\     运行日志（网站日志 demo-app.log 在这里，出问题先看它）

端口说明（故意避开常用端口，避免和你机器上已有的服务打架）：
   MySQL 3307   Redis 6380   网站 10090
所以：如果你自己已经装了 MySQL(3306)/Redis(6379)，它们不受影响。


三、需要装什么
----------------------------------------------------------------
理论上：什么都不用装。
唯一可能的例外是 Windows 缺少微软 C++ 运行库（老机器偶尔遇到）：
   现象：MySQL 窗口一闪而过，日志里写 "VCRUNTIME140.dll was not found"
   解决：装一次 "Microsoft Visual C++ 2015-2022 Redistributable (x64)"
        （微软官网免费下载，约 25 MB；装完重新双击 1-start.cmd）


四、常见问题
----------------------------------------------------------------
Q: 双击 1-start.cmd 后窗口一闪就没了？
A: 说明它没找到同目录下的 app / runtime / mysql。
   99% 是没有完整解压（或只解压了部分文件）。请解压整个文件夹后再试。

Q: 提示 10090 已被占用？
A: 你本机可能已经有别的程序占了这个端口（例如上一次没关干净的实例）。
   先双击 2-stop.cmd，再重新启动。

Q: 页面能打开但登录报错？
A: 多半是 MySQL 还没起来（第一次启动最慢）。等 10 秒刷新一次；
   仍不行就看 logs\demo-app.log 的最后几行。

Q: 我想把数据恢复到最初的 45 篇文档？
A: 双击 2-stop.cmd 停止，然后把 mysql\data 换成压缩包里的原始副本
   （如果你提前备份过），或者用源码版里的 backend\sql\schema.sql + data.sql
   在一个能连上 3307 的客户端里重灌（root 空口令，仅本机演示用）。

Q: 会不会影响我电脑上已经装的 MySQL / Node / JDK？
A: 不会。这里所有程序都只在本文件夹内运行，用的也是独立端口；
   停止后不留后台进程、不写注册表、不装服务。
