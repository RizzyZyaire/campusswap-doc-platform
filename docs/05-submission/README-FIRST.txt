一、只想快速看效果 —— 两步，不用装任何东西
----------------------------------------------------------------
  1) 解压整个压缩包到任意目录（不要在压缩软件里直接双击运行）
  2) 进【一-双击运行（免安装）】，双击【1-启动网站（双击我）.cmd】
     等 10~30 秒，浏览器自动打开 http://localhost:10090
     演示账号：admin/Admin@123、docadmin/Doc@123456、staff/Staff@123
     停止：双击同目录的【2-停止网站（双击我）.cmd】

  这个包里自带：精简 Java 运行时 + 便携 MySQL（数据已灌好）+ 便携 Redis，
  所以不装 JDK、不装数据库、不跑 SQL、不用 Node，双击即可。
  更细的说明和排错见【一-双击运行（免安装）\使用说明.txt】。

五、常见问题（详见一-双击运行（免安装）\使用说明.txt）
----------------------------------------------------------------
  · 双击后窗口一闪而过 → 多半是没完整解压，请解压整个文件夹后再试
  · 提示缺 VCRUNTIME140.dll → 装一次微软 "VC++ 2015-2022 Redistributable (x64)"
  · 10090 被占用 → 先双击【2-停止网站（双击我）.cmd】，再重新启动
  · 端口是 3307 / 6380 / 10090，故意避开 3306 / 6379，不会影响你机器上
    已有的 MySQL / Redis
